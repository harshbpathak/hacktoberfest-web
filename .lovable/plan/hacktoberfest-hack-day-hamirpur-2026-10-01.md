# Hacktoberfest Hack Day Hamirpur

## Build
- Replace the blank page with one smooth-scrolling event page and sticky section navigation.
- Create the dark retro-futuristic visual system using neon Hacktoberfest energy, Google accent colors, monospace typography, restrained glass surfaces, and accessible contrast.
- Add an animated Git branch and AI-node scene to the opening view, with reduced-motion support.
- Build About, Benefits, Prize Pool, Sponsors, Sponsorship, and Footer sections in the requested order.
- Add reusable `Button`, `Card`, and `PrizeCard` pieces, mobile navigation, working anchor links, email, WhatsApp, and social links.

## Technical details
- Use React, Tailwind CSS v4, Framer Motion, Lucide React, and shadcn-style variants.
- Keep all visual values in semantic tokens in the global stylesheet.
- Add unique page metadata and load the selected display/body fonts from the document head.
- Verify the page at desktop and mobile widths, test navigation links, and confirm no runtime or build errors.
